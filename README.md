# 🍽️ NomNom

**NomNom** is an interactive educational game designed to help 1st-grade students learn basic math through play.  
The game focuses on **counting and problem-solving** using visual feedback, animations, and simple interactions instead of text.

## Features

- **Two interactive mini-games**
  - *Counting Hands* – Match numbers to the correct number of fingers
  - *Feed the Monster* – Select the correct ingredients to solve problems
- **Visual-first design** – Minimal text, ideal for early learners
- **Feedback system** – Animations and sounds reward correct answers
- **Game-based learning** – Encourages engagement through play

---

## Tech Stack

- **Engine:** Godot (GDScript)
- **Focus:** UI/UX design, game logic, interactive learning mechanics

---

## How to Run

1. Install [Godot Engine](https://godotengine.org/)
2. Clone this repository
3. Open the project in Godot
4. Run the main scene
